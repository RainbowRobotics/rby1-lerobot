# lerobot-teleoperator-rby1

LeRobot teleoperator plugins for the Rainbow Robotics RB-Y1:
leader arm (`--teleop.type=rby1_leader_arm`), Meta Quest VR (`--teleop.type=rby1_vr`) and
XR headset through NVIDIA Isaac Capture (`--teleop.type=rby1_isaac`, install with the
`isaac` extra: `pip install -e "lerobot-teleoperator-rby1[isaac]"`).

Requires Python 3.12+ and `lerobot>=0.7.0,<0.8`. See the
[repository README](https://github.com/RainbowRobotics/rby1-lerobot) for setup,
configuration options and usage.
