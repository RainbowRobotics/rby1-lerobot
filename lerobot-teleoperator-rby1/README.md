# lerobot-teleoperator-rby1

LeRobot teleoperator plugins for the Rainbow Robotics RB-Y1:
leader arm (`--teleop.type=rby1_leader_arm`) and Meta Quest VR (`--teleop.type=rby1_vr`).

Requires Python 3.12+ and `lerobot>=0.6.1,<0.7`. See the
[repository README](https://github.com/RainbowRobotics/rby1-lerobot) for setup,
configuration options and usage.
